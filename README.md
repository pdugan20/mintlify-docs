[![License: MIT](https://img.shields.io/badge/License-MIT-yellow?logo=opensourceinitiative&logoColor=white)](https://opensource.org/licenses/MIT)

This project has moved to the combined
[`pdugan20/skills`](https://github.com/pdugan20/skills) collection. This
repository remains available as read-only history for its source, releases,
issues, and incoming links. Do not start new installations from this repository.

## Install the replacement

```bash
npx skills@latest add pdugan20/skills
```

Claude Code and Codex marketplace users should install
`patrick-skills@patrick-plugins`, then remove
`mintlify-docs@patrick-plugins`.
